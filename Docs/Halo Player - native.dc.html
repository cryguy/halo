Chips state what is playing

Subtitles, audio, speed and the episode read their current value on the bar, so the six-icon guessing game disappears. Each one opens the rail on its own tab.

One rail, three tabs

Replaces the 48%-wide side sheet and the full-screen three-column subtitles overlay. The video stays visible, which matters when you are tuning subtitle size or delay against it.

Format-aware subtitles

ASS, SRT and PGS tracks are labelled as such. Size, delay and font apply live through setSubtitleScale / setSubtitleFont; for ASS, keeping track styling means the script's own fonts and positions stay intact and only scale changes.

Back chevron, chevron-down, play, close and check are the app's own Material path data lifted verbatim from HaloIcons.kt. Pause, PiP, fit, lock, brightness, volume, seek and grid are prototype stand-ins — that file does not carry them yet.

Bitmap tracks are honest

PGS is rendered images, so font and outline do not apply to it — the rail says so rather than offering controls that do nothing.
